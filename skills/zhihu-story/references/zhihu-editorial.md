# 知乎盐选编辑标准

## 一、盐选黄金结构

| 位置 | 要求 |
|------|------|
| 前 200 字 | 高潮切入，抛出最吸引人的悬念。故事回答场景下，开头必须是事件高潮而非背景铺垫 |
| 前 1000 字 | 明确主角核心欲望 + 动机，让读者迅速掌握故事核心亮点 |
| 前 3000 字 | 预埋核心悬念，用钩子勾着读者往下读 |
| 前 1/3 或 1/2 | 设置大转折或小高潮 |

### 发展阶段
- 接住开头抛出的主线 + 欲望 + 动机
- 情节发展要快，冲突要激烈
- 每千字至少一个看点

### 高潮部分
- 上承发展、下启结局，全文最大的转折点
- 开头抛出悬念 → 发展强化悬念 → 高潮解开悬念
- 满足读者期待感，意料之外、情理之中

### 收尾阶段
- 人物结局交代清楚
- 升华主题，耐人寻味
- 价值观飙升

## 二、人物要求

- 开篇人物不超过 3 个，人物关系简单
- 人设真实细腻、立体丰满、个性突出
- 追求极致性 / 反差萌 / 两极反转
- 干净利索有张力
- 每个人物出现都增加一道阅读门槛，所以控制人数
- 配角必须有特色（脸上有道疤、说话结巴等），打破陌生感

## 三、编辑选稿标准

1. 一句话能提炼出核心亮点
2. 开篇干脆不拖沓，把最吸引人的情节、主角最核心的欲望提炼出来
3. 中段三看点：核心悬念、人物张力、文稿创意——用新视角解决故事中的旧元素
4. 结局形成完整闭环，危机解除后让读者长吁一口气

## 四、过稿防拒指南

### 拒稿理由 1："情节设计套路化或情节张力不足"
- 每个章节必须有独特的叙事功能，不能换皮重复上一段的冲突模式
- 冲突升级而非重复：每个冲突的赌注必须比前一个更大
- 用"如果去掉这段情节故事还成立吗"测试——不成立才说明不是注水
- 结局要有具体画面和情感余韵

### 拒稿理由 2："文笔流畅度有待提高"
- 每句话控制在 15-25 字
- 动词优先，减少形容词堆砌
- 对话占比保持 30-40%，纯叙述不超过连续 500 字

### 拒稿理由 3："剧情逻辑经不起推敲"
- 角色每次行动都要有动机
- 巧合每段最多1个，用了后面必须有合理解释
- 角色能力稳定，时间线自洽

### 拒稿理由 4："读者代入感较弱"
- 开篇 200 字内锁定主角并引发好奇心
- 用感官细节代替抽象描述："冷"写成"她缩了缩脖子，围巾上还挂着没化的雪粒"
- 对话像真人说话：短句、省略、有情绪、有潜台词
- 每 1000 字让读者产生一次情绪反应（紧张/心疼/爽/想笑/愤怒）

## 五、盐选 vs 故事回答开头差异

- **盐选专栏**（书店式场景）：读者专门来读，有耐心 → 可以从事件背景切入
- **故事回答**（社区式场景）：读者只是对问题感兴趣 → 必须从事件高潮切入
- **默认按故事回答场景写**——高潮切入的开头在两种场景下都不会出错

## 六、选题三要素

1. **题材**：有积累有作品 / 平台读者反响热烈
2. **主题**：源于生活、高于生活，不以三俗博眼球，不以立场引矛盾
3. **卖点**：选题新颖、设定出彩、人物有梗、反转不断、每段埋钩子

## 七、禁忌清单

- 开头用"我叫xxx，是一个xxx"的自我介绍
- 所有线索集中在最后揭示而前文没有伏笔
- 为了反转而反转，逻辑经不起推敲
- 在悬疑故事里插入大段抒情或感悟
- 每千字没有看点
- 开篇人物超过3个
- 写纯过渡段落——每一段都必须有信息量或情感推进
- 第一人称叙述中用"我心想""我暗道"——直接写想法
- 用旁白总结人物性格——用行为展示
- 超过2句的纯景色描写
