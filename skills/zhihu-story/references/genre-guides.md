# 类型专属写作指南

## 古言

古代或架空古风社会文化背景下，以男女主角感情线为主线的故事。鼓励将传统元素和创新元素融合。

### 子类型

| 子类型 | 核心卖点 | 关键元素 |
|--------|----------|----------|
| 甜宠 | 关系张力 + 情感拉扯 | 可叠加先婚后爱、日久生情 |
| 追妻火葬场 | 女性掌握主动权 + 打脸渣男 | 双倍爽感，男主追妻要有诚意 |
| 权谋 | 个人命运与家国情怀 | 商贾世家/后宅+大女主+女性成长互助 |
| 穿书/重生 | 金手指 + 逆天改命 | 开局就有悬念，利用前世记忆制造信息差 |
| 种田经商 | 生活流 + 逆袭 | 从底层一步步翻身，穿插感情线 |
| 玄幻仙侠 | 修炼/打怪推动情节 | 需要简洁的修炼体系，不要太复杂 |

### 穿书/重生写作要点

1. **前世记忆是核心工具**：主角利用前世记忆制造信息差，但不要开挂过度——每次使用都要有代价或限制
2. **原主身份认同危机**：穿书/重生后要有身份融合的内心戏，不能完全像另一个人
3. **原著剧情线利用**：知道原著走向是优势，但剧情线会因主角介入而偏移，制造新的不可预知性
4. **与原主角的关系处理**：不要简单粗暴地抢夺原主角的资源/人脉，要有合理的情感逻辑
5. **金手指限制**：前世记忆不能解决所有问题，要有记忆模糊/信息过时的时刻
6. **身份暴露危机**：至少设置一次差点被识穿的危机，强化紧张感

### 苏点设计
- 男女主情感暧昧的极限拉扯感
- CP感是核心：妖娆笨蛋美人 vs 运筹帷幄皇子、病娇恋爱脑王爷 vs 暴躁小娇妻
- 男主人设符合女性幻想（可以腹黑病娇，但要有讨喜的点）
- 女主要有亮点（性格优势或金手指）

### 虐点设计
- 男女主身份地位对立
- 遗憾错过、宿命感冲突
- 虐要有度，有回甘

### 古言文笔要求
- 语言半文半白：用"道"不用"说"，用"倏然"不用"突然"——但不堆砌生僻字
- 称谓体系：郎君/娘子/阿兄/胞弟/庶妹/继母等，符合身份和亲疏关系
- 服饰器物有质感：用"朱红披风""流光锦缎"等具体名称
- 动作描写有古风美感
- 对话符合古代礼制：有尊卑、有礼数、有分寸感

### 代入感5法
1. 开篇强冲突——情绪是进入故事最快的方式
2. 主角人设真实可感——高地位人设用情绪加强代入
3. 多用细节描写——用细节代入角色视角
4. 动机合理化——主角动机需结合所处环境
5. 配角特色化——外貌或行为特征打破陌生感

## 现代言情

当代都市背景下的爱情故事。

### 子类型

| 子类型 | 核心卖点 | 关键元素 |
|--------|----------|----------|
| 甜宠 | 高甜 + 日常撒糖 | 职场/校园/邻里，甜中有冲突 |
| 先婚后爱 | 契约 → 真情 | 假结婚/闪婚/相亲，身份差是调味 |
| 豪门 | 阶层冲突 + 身份差 | 灰姑娘/落魄千金，反转要有力 |
| 破镜重圆 | 旧情 + 误会解开 | 分手原因要合理，重逢不能靠巧合 |
| 悬爱 | 爱情 + 悬疑线 | 双线交织，悬疑推动感情发展 |

### 现代言情文笔要求
- 对话口语化，不要文绉绉
- 可以用网络用语但要克制
- 场景描写贴近生活（外卖、地铁、办公室），不要太文艺
- 职业设定要有基本真实感

## 悬疑

以悬念、推理、反转为核心驱动力的故事。

### 子类型

| 子类型 | 核心卖点 | 关键元素 |
|--------|----------|----------|
| 本格推理 | 逻辑严密的破案 | 线索公平呈现，读者可以推理 |
| 社会派 | 人性探讨 + 社会议题 | 犯罪动机是核心，不是手法 |
| 恐怖悬疑 | 氛围 + 反转 | 前80%营造恐惧，结尾反转揭示真相 |
| 日常悬疑 | 身边的秘密 | 邻居/同事/家人的隐藏面，细思极恐 |

### 悬疑文笔要求
- 精准控制信息释放节奏
- 善用误导和反转
- 场景描写营造不安氛围
- 对话暗藏线索
- 叙事视角切换要有策略性
- 绝对不能在悬疑段落里插入大段抒情

## 脑洞

以独特设定或创意为核心卖点的故事。

### 常见方向
- 非人类视角（猫/鬼/AI/物品作为叙述者）
- 规则类（特殊世界规则 + 求生）
- 反转流（不断颠覆读者认知）
- 荒诞喜剧（严肃外壳下的荒诞内核）

### 脑洞文笔要求
- 设定要在前500字内建立
- 规则要简洁明确，读者不需要重读就能理解
- 用角色的实际体验展现规则，不要列清单式介绍
- 脑洞再大，人物情感必须真实
